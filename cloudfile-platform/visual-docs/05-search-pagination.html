Search & Pagination

Move the sliders to see how page and page_size turn into a SQL OFFSET/LIMIT and page math.

How the repository builds the query

SELECT * FROM files WHERE owner_id = :me AND filename ILIKE '%:name%' -- optional AND content_type = :type -- optional ORDER BY created_at DESC OFFSET :offset LIMIT :limit; -- pagination # A separate COUNT(*) gives `total`, used to compute total_pages.
Security: every query is scoped to owner_id = me (from the JWT), so a user can only ever see their own files.
