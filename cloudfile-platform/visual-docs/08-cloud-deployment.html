Cloud Deployment on AWS

Two animations: the CI/CD pipeline that ships your code, and the AWS topology it runs on. Free-tier-first.

💸 Cost reminder: always run terraform destroy after testing. EKS control plane and NAT gateways bill hourly. The default path uses ECS Fargate + Lambda + S3 + RDS db.t3.micro to stay cheap.

The commands

cd cloudfile-platform/infra/terraform terraform init export TF_VAR_db_password=$(openssl rand -hex 16) export TF_VAR_jwt_secret_key=$(openssl rand -hex 32) terraform apply # VPC, ECR, S3+trigger, Lambda, RDS, ECS # build + push images, then force ECS to redeploy (CI/CD does this for you) terraform destroy # ⚠️ ALWAYS when done
