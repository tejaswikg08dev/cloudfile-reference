The Upload Journey

This is the flow to show in interviews. Press Play and follow the 📄 file token through the whole system.

Why this design? The client uploads bytes directly to S3 via a presigned URL, so the service never proxies large files and stays stateless. The async Lambda keeps heavy work (thumbnails) off the request path. Notifications are fire-and-forget, so they never block the upload.
