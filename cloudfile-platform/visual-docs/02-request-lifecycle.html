A Request's Lifecycle

Every service follows the same clean layering. Watch a request flow down and a response flow back.

Why layer it? Each layer has one job. Routers never touch SQL; services never touch HTTP; repositories never contain business rules. This makes the code testable (swap the DB for SQLite in tests) and easy to reason about.
